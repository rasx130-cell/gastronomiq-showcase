# GastronomIQ — таныстырылым сайты

Мектептегі тамақтануды ұйымдастыру жобасының қазақша таныстырылымы. Сайтта веб-кабинеттердің шолуы, Android қолданбасынан жазылған бейне және Telegram мен WhatsApp батырмалары бар. Экрандар сынақ деректерімен түсірілген.

[Сайтты ашу / Открыть сайт](https://gastronomiq-showcase.famedprimrose2.chatgpt.site/)

## Локалды ашу / Локальный запуск

Из этой папки запустите `python -m http.server 8000`, затем откройте `http://localhost:8000/`. Для размещения скопируйте содержимое папки на статический хостинг. Сборка и API-ключи не нужны. Для глав видео нужен HTTP-сервер.
